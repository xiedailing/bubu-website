## 驗證

先依 README 啟動靜態伺服器，再使用本機開發工具提供的 Playwright 模組執行：

```powershell
node scripts/verify-solution.cjs <Playwright模組路徑> ./artifacts/solution-qa
node scripts/verify-insights.cjs <Playwright模組路徑> ./artifacts/insights-qa
```

檢查 320、390、700、768、1024、1280、1440、1920px：整頁橫向溢出、文字裁切、六個區塊、九張截圖的來源及有效尺寸、插圖載入、固定導覽遮擋、章節定位與上一頁。每種寬度逐一驗證九張圖片開啟正確原圖、Escape 關閉與還原焦點；另以 iPhone 13 模擬觸控開關視窗及減少動態效果。

輸出報告及 1440px／390px 的六區塊截圖於 `artifacts/solution-qa/`。已人工比對桌機與手機截圖。新增章節八種寬度與手機觸控皆通過，無 JavaScript 或 HTTP 載入錯誤；另確認三張方向卡的標籤與插圖在全部測試寬度都不重疊。既有 03 章節八種寬度檢查也通過，首頁與研究章節另檢查 390px／1440px 的素材載入、章節高亮及整頁溢出。`node --check` 及 `git diff --check` 通過。手機驗證使用 Windows Edge 裝置模擬，未使用實體 iOS／Android 裝置。
