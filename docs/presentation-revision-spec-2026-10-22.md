## 2. 專案現況與檔案地圖

本專案是簡報用靜態網站，使用 HTML、CSS、JavaScript，非 Vue 產品原始碼。

| 檔案 | 責任 |
| --- | --- |
| `index.html` | 所有章節、文字、卡片、表格、圖片與錨點 |
| `styles.css` | 共用樣式、導覽、01、研究與洞察等區域 |
| `navigation.js` | 章節導覽與捲動時顯示／隱藏頁首 |
| `solution.css` | 設計方向、資訊架構、核心流程 |
| `iteration.css` | 迭代 A、B、C 排版 |
| `results.css` | 成果、學習、團隊、未來方向 |
| `solution.js` | 圖片放大、切換與縮放預覽 |
| `public/assets/` | 本地 SVG、截圖、插圖與字型子集 |
| `scripts/verify-*` | 各區域既有驗收腳本；部分斷言綁定舊內容，需隨本次需求更新 |

重要的現況對應：

- 使用者所稱的 `div.daily-moment`，目前實際為 `.everyday-moments`。
- 導覽列已是 `position: sticky; top: 0`，但 `navigation.js` 會在向下捲動時加入 `.is-hidden`，使頁首消失。
- 目前章節標示只隨網址 hash 更新，手動捲動不會正確更新所在章節。
- 「03／定義問題」對應 `.insights-definition`，不是整個 `#insights`；關鍵洞察卡片要保留。
- 目前網站的 05 是迭代。新增「05 設計」尚在等待設計，本輪不先把所有後續章節重編。
