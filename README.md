# 補補 Bubu｜發表網站

由 Figma 設計稿開發的發表網站（桌機 1440 寬）。**設計稿仍在修改中**，開發前請重新讀取最新 frame，不要依賴本文件的尺寸或文案。

## 本機預覽（目前完成：首頁、導覽列、02 研究、03 洞察、04 解法、05A–C 迭代與 06 Demo）

直接開啟 `index.html`，或在專案根目錄執行：

```powershell
python -m http.server 5173 --bind 127.0.0.1
```

瀏覽 <http://localhost:5173>。使用原生 HTML / CSS / JavaScript，無需安裝套件或建置，可直接部署為靜態網站。

首頁依 `289:243` 實作，包含產品介紹、品牌 Logo、生活主視覺及兩張日常補貨情境卡。1440px 桌機版依 Figma 的字級、圖片尺寸與間距呈現；窄螢幕調整為單欄，手機版情境卡採上下圖文。

導覽列依最新 `291:232` 實作：桌機高度 86px、1440px 時左右留白 64px。手機版上下兩列，章節連結可水平捲動，也支援鍵盤操作。點擊章節會更新網址與目前章節樣式，支援瀏覽器上一頁／下一頁。07 章節目前僅有空白容器，捲動追蹤待後續建置。

02 研究依 `312:423` 實作，包含研究方法與兩種使用情境、競品比較與三個設計問題、四項研究發現，以及五階段使用者旅程。沿用同一個固定導覽列，省略 Figma 各展示畫面間重複的導覽列。1440px 保留多欄卡片、五欄旅程、字級與留白；手機改為單欄，競品表格可橫向捲動及使用鍵盤方向鍵操作。詳見 [研究章節實作與驗證](docs/research-implementation.md)。

03 洞察依 `315:492` 實作，包含三項設計考量、核心／輔助／情境延伸標籤、研究依據，以及核心問題定義。桌機保留三欄卡片與設計稿留白，1100px 以下改為單欄，手機調整字級與留白。沿用既有導覽與原生章節連結。詳見 [洞察章節實作與驗證](docs/insights-implementation.md)。

04 解法依再次確認的連結 `317:538` 實作，包含三個設計方向、資訊架構、三組核心流程與設計取捨。流程截圖可點擊或以鍵盤開啟放大視窗，支援 Escape／關閉按鈕；手機改為直向步驟與架構層級。新增樣式與互動分別位於 `solution.css`、`solution.js`。詳見 [解法章節實作與驗證](docs/solution-implementation.md)。

圖片、Logo 與 Chiron GoRound TC 的 400／500／700 字重皆存放於 `public/assets/`，預覽無需連線至 Figma 或 Google Fonts。首頁保留原字型子集，研究、洞察與解法章節分別使用獨立的 `chiron-research-*.ttf`、`chiron-insights-*.ttf`、`chiron-solution-*.ttf` 子集；新增文案時需檢查字元涵蓋範圍。授權見 `public/assets/chiron-OFL.txt`。

05A 迭代依 `289:244` 實作，包含兩項測試觀察、設計調整與版本差異、五張新舊版截圖對照。桌機沿用原稿尺寸與留白；手機改為單欄，保留完整截圖。沿用既有圖片放大視窗與章節導覽，新增樣式位於 `iteration.css`，使用獨立的 `chiron-iteration-{400,500,700}.ttf` 字型子集。詳見 [迭代 A 實作與驗證](docs/iteration-implementation.md)。

06 Live Demo 依 `324:921` 實作，包含個人補貨與家庭共同採買的操作步驟、另開新分頁的產品入口、備援說明及單機模擬註記。桌機雙欄、手機單欄，新增樣式位於 `demo.css`，使用獨立的 `chiron-demo-{400,500,700}.ttf` 字型子集。備用錄影尚未提供，備援列目前為說明文字。詳見 [06 Demo 實作與驗證](docs/demo-implementation.md)。

## 開發順序（預計）

1. Figma 定稿後，用 Figma MCP 讀 frame 取得 variables 與文字樣式 → 整理到 `docs/`
2. 匯出素材到 `public/assets/`
3. 選定框架並建立專案（發表用靜態展示站；Vite 或 Next.js，部署到 Vercel）
4. 逐章節實作，與 Figma 對照
5. 推到 GitHub，連 Vercel 自動部署
